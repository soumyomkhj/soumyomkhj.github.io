# Components

Reusable HTML components for the portfolio site.

## Available Components

- `nav.html` - Navigation bar for homepage
- `nav-project.html` - Navigation bar for project pages
- `preloader.html` - Loading screen component
- `cursor.html` - Custom cursor/follower component

## Usage

Components can be loaded using the ComponentLoader utility:

```javascript
ComponentLoader.load('nav', 'components/nav.html');
```

Or include them directly in HTML using the component loader script.
